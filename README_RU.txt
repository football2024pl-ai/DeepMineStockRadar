DEEPMINE STOCK RADAR — САЙТ И ПОДКЛЮЧЕНИЕ К ИГРЕ
=================================================

Что внутри
----------
public/index.html — красочный адаптивный сайт с тремя верхними кнопками: «Сток аур», «Сток яиц», «Сток кирок».
server.js — Node.js API, которое принимает снимки от Roblox и отдаёт их сайту.
roblox/DeepMine_v1_Server_GLOBAL_STOCKS_WEBSITE_BRIDGE.lua — полный MineServer с добавленным мостом к сайту.
.env.example — пример переменных сервера.

ВАЖНО: сайт не генерирует отдельный случайный сток. Он получает снимок из текущей логики DeepMine: auraStockSnapshot(), eggStockSnapshot() и pickaxeStockSnapshot(). Отображаемые количества — базовый сток текущего 5-минутного цикла. Покупки в самой игре остаются индивидуальными для каждого игрока, поэтому сайт не отображает персональный остаток конкретного игрока.

ЧАСТЬ 1. Разместить сайт и API
-----------------------------
1. Распакуй архив и загрузи содержимое папки DeepMineStockWebsite в новый приватный или публичный GitHub-репозиторий. Не добавляй в репозиторий свой секрет/API-ключ.
2. На хостинге, например Render, создай новый Web Service и подключи этот репозиторий.
3. Runtime: Node. Build Command: npm install. Start Command: npm start.
4. В Environment Variables добавь STOCK_API_KEY со своим длинным случайным секретом (не используй текст-заглушку). Этот ключ не должен публиковаться на веб-странице или в GitHub.
5. После публикации у сервиса появится адрес примерно https://имя-сервиса.onrender.com. Открой его — главная страница сайта должна загрузиться. До подключения Roblox будет сообщение «Ждём подключение DeepMine».
6. /api/health должен отвечать JSON-статусом. Не нужно вручную добавлять каталог предметов в сайт.

ЧАСТЬ 2. Подключить Roblox
--------------------------
1. В Roblox Studio открой Game Settings / Experience Settings → Security и включи Allow HTTP Requests.
2. В Creator Dashboard выбери свой Experience → Secrets → Create Secret. Имя: DeepMineStockApiKey. Значение должно в точности совпадать с STOCK_API_KEY из Environment Variables хостинга. В поле домена разреши hostname своего сайта, например my-deepmine-site.onrender.com (без https:// и без /api/roblox-stock).
3. В файле roblox/DeepMine_v1_Server_GLOBAL_STOCKS_WEBSITE_BRIDGE.lua найди:
   local STOCK_BRIDGE_URL = "https://REPLACE-ME.onrender.com/api/roblox-stock"
   и замени адресом своего сайта с окончанием /api/roblox-stock.
   Пример: https://my-deepmine-site.onrender.com/api/roblox-stock
4. В ServerScriptService замени MineServer полным содержимым файла из папки roblox. Не создавай второй MineServer. Сделай резервную копию прежнего скрипта.
5. Опубликуй игру. После запуска хотя бы одного игрового сервера снимок отправляется при старте, при смене 5-минутного цикла, а также как резервная синхронизация раз в 3 минуты (проверка идёт раз в 20 секунд). Затем обнови сайт: должны появиться реальные предметы и их количество.

ПРОВЕРКА
--------
- Чтобы тестировать секрет в Studio, используй Local Secrets в File → Experience Settings → Security; обычное хранилище Secrets доступно опубликованным серверам и collaborative testing, но не обычному локальному Play.
- Сначала проверь сайт без Roblox: главная страница открывается, API /api/health отвечает.
- Запусти опубликованную игру и смотри Server Output на предупреждения с префиксом [DeepMine Website].
- Если видишь «Не найден секрет Creator Hub 'DeepMineStockApiKey'», проверь имя секрета и доступность секрета этому Experience.
- Если видишь HTTP-ошибку, проверь URL, что он заканчивается /api/roblox-stock, и совпадение STOCK_API_KEY с секретом.
- Если сайт пишет, что ждёт игру, значит сервер ещё не отправил первый снимок или мост не настроен.
- Веб-сервис хранит последний снимок в памяти процесса. После перезапуска хостинга сайт снова получит снимок от активного сервера; обычно это происходит в пределах следующего интервала отправки.

БЕЗОПАСНОСТЬ
------------
Сайт может публично читать только сток. Публикация защищена секретным ключом, который отправляет только серверный MineServer. Не переноси ключ в index.html или LocalScript.

Официальная документация Roblox по HTTP-запросам:
https://create.roblox.com/docs/cloud-services/http-service
Документация Render для Node/Express:
https://render.com/docs/deploy-node-express-app

Техническая проверка
--------------------
Пакет включает реальную интеграцию исходника MineServer с API, но не содержит уже опубликованного сайта: публикация требует аккаунта хостинга и настройки Secret владельцем опыта. Сайт не считается подключённым к живой игре, пока не выполнены шаги Части 1 и Части 2.
